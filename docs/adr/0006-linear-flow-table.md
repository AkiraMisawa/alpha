# 線形フローはネッティングセットごとのフロー表に畳み込む

線形フローの将来時価は、支払日と通貨で決まる割引債価格に金額を掛けたものの和になる。そこで評価日に、ネッティングセット内の線形フローを通貨、支払日、露出終了日ごとに足し合わせたフロー表を作り、各時点ではこの表を評価する。変動金利のフローは、期初に元本を受け取り期末に支払う形に置き換えて表に入れる。

評価のコストが取引件数ではなく支払日の数で決まるようになり、サーバ1台で計算し切るための主な手段になる。

## Consequences

- 取引別の将来時価は既定では得られない。必要なときは畳み込まない経路で計算する。
- 指標の金利と割引金利の差は、確定的なスプレッドとして扱う。
- 支払日のずれなどで解析式を用意できないフローは、線形フローとして扱わず回帰に回す。
