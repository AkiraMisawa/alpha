# AADは全パスの配列を1ノードとする自作テープで実現する

有料ライブラリを使わないという条件がある。AADC と dco/c++ は商用で、XAD は AGPL-3.0 のため非公開の業務システムに組み込むと実質有料になる。そこで外部のAADライブラリは本体に入れず、全パスぶんの配列を1ノードとするテープを自作する。

回帰と集約の随伴はどのライブラリを使っても手書きになるので、自作の負担の増加は基本演算の随伴に限られる。

## Considered Options

- XAD: 導入は簡単だがライセンスの条件に合わない。
- Enzyme（Apache-2.0）: Clang/LLVM が前提で、MSVC では使えない。遅い箇所が見つかった時点で、部分的な利用を検討する。
- CoDiPack などの無料ライブラリ: テストでの照合用に限って使う。

## Consequences

- テープ全体を一度に記録するとメモリに収まらない。時点チェックポイントを取り、時点、取引、パスのブロックごとに記録と逆伝播を行う。
- テープはグローバル変数やスレッド固有の変数として持たず、相手先タスクが所有するオブジェクトとして明示的に渡す。多くのAADライブラリとは逆の作りだが、スレッドセーフにし、スレッド数によらず同じ結果を得るためである。
