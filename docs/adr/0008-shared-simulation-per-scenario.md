# シミュレーションはリスクシナリオごとに1回行い、相手先タスクで共有する

相手先タスクは互いに独立だが、市場のパスは相手先によらない。そこで1回の起動の中では、リスクシナリオごとに全通貨のパスを1回だけ作り、読み取り専用のデータとして全相手先タスクが参照する。相手先ごとに作り直す無駄がなくなり、どの相手先も同じパスを使うことが保証される。逆伝播では、各相手先タスクは自分が使う通貨の分だけをたどる。

別の起動とはパスを共有しない。乱数の状態はシードだけで決まるので、どの起動でも同じパスが再現される。

## Consequences

- 通貨20、200時点、16,384パスで、パスの保存に約1GBを使う。
- 1次リスクは相手先ごとに出し、合計はその和とする。
