# 計算の単位を相手先にし、XVAは単独値を正とする

既存システムは、スキップグループごとの回帰ジョブがすべて終わるのを待ってから集計していた。新しい仕組みでは相手先を1タスクとし、順方向と逆方向をその中で完結させる。FVA、ColVA、MVAも相手先単位の単独値を正とし、相手先をまたぐ集約は当面は対象外にする。

こうすると、タスク間でパス×時点のベクトルをやり取りする必要も、全体の待ち合わせもなくなる。

## Consequences

- 調達と運用のスプレッドが非対称な場合、FVAの合計はポートフォリオ全体で計算した値より大きく出る。
- CVA資本のように相手先をまたいで集約する指標は、後段の集約を別に作らないと分散効果が入らない。
- 取引の多い相手先はタスクが重くなるので、タスク内で並列化する。
